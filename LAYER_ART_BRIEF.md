# Layer Art Brief — Tortuga Cove

**137 separate generations.**

Generated from the island blueprint (`tools/blueprint/plan_tortuga.py`) by `tools/blueprint/brief_layers.py`.
Re-run it after the plan changes. Each layer below is painted on its own, in this order, and each asset is
traced from the matching plan layer (`tools/blueprint/layers/*.svg`) so the art lands exactly on the plan.

## Rules for every generation

- **One asset per image: a single isolated item, not a sheet, grid, row or collage of several items.** If a group below lists several items, each one is still its own separate image generation.
- Match the attached MASTER_STYLE_harbour.png: dense retro pixel art with visible pixel grain, high top-down three-quarter view (large roof seen from above, front wall plus a little side wall), weathered Caribbean pirate port, warm terracotta roofs, crisp dark outlines.
- Flat pure-green (#00FF00) background for keying, no shadow on the background, no text, no border.
- Sizes: footprints are in world units (1 unit = 7 screen px at map zoom). Generate at about 21 px per unit, then downscale.
- Attach the plan layer crop for that asset as a second reference so the footprint, roof ridge and door match.
